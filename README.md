# Sistema de Reservas de Equipos Audiovisuales

Proyecto #2 de Tópicos Especiales II, impartido por el profesor Regis Rivera. El equipo desarrollará una aplicación web académica que simula el alquiler de equipos audiovisuales y permite reservar unidades físicas por intervalos de tiempo.

## Alcance acordado

El MVP comprende registro e inicio de sesión, catálogo y categorías, inventario de unidades físicas, consulta de disponibilidad, creación y consulta de reservas propias, cancelaciones, prevención de reservas superpuestas y administración básica de equipos. La posible inclusión de pagos se mantiene pendiente de aprobación.

## Flujo de trabajo

1. Aplicar ODD para documentar usuarios, problemas, hipótesis y resultados esperados.
2. Aplicar SDD para convertir esos resultados en especificaciones y criterios de aceptación verificables.
3. Preparar la aplicación base y sus pruebas técnicas. El catálogo, el inventario y las reservas se desarrollarán en sus respectivas Issues.

El equipo usará el laboratorio 13 como referencia del trabajo académico. Cada entrega se vinculará a una Issue y se desarrollará en una rama con commits identificables y un Pull Request contra `main`. Los cambios de requisitos se documentarán cuando aparezcan durante el desarrollo.
